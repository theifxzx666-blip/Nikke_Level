## 4. 已撤销的判断：#2「分卷加成未计」

v1 报告把官方 `6_其他产出` 的「分卷加成奖励 ×50」列为**模板未计**，是**误判**。

**证据**：
1. 模板**每一关**的 tokens 都恰好等于官方清关奖励 base **+50**，24/36 关 + 14 天 24 关**无一例外**，连官方 base 为 0 的一次性关也记 50。
2. 官方该条奖励的备注是 `BonusRewardCharacterGroup=75/76`——**活动加成角色**的每关加成，天然是「每关每次都给」。
3. 用户实测：**扫荡 S2H1-11 一次，代币 = 100**。官方该关 base = 缘分锁链×50 → 50 + 50 = 100，完全咬合。

**结论**：模板的 `+50` 就是这条分卷加成，**已计入**。v1 建议的「再 +50/+100」会导致**重复计算**，v2 已删除。相应地，v1 的数值影响表整体下调了 50/100 token 对应的信用点（large21 4,592K → 4,572K 等）。
