参考 `merlot-sve.xyz`《升级资源计算器 v1.6》的「识图导入」功能。

## 二、技术选型（均为实测）

| 方案 | 实测结果 | 结论 |
| :--- | :--- | :--- |
| **RapidOCR**（本机服务，`engine=.venv`） | 资源/等级 6/6 全对；物品栏时长 10/10、数量抽查 14 格全对 | ✅ **采用** |
| Tesseract.js 7.0.0（纯前端离线） | `22762→255085K`、`240M→255MK`、`6738→5796138` | ❌ 仅作无服务时的降级 |
| 数字模板匹配（参考项目的 `OCR_TEMPLATE_DATA`） | 数字与中文粘连（`22762` 切 3 块、`14,000` 把 `14` 并一块）；样本只覆盖 0-8 | ❌ 放弃 |
| 图标模板匹配箱型 | 240px 图标 → 94px 格子，`matchTemplate` 全格命中同一模板，分数 0.4~0.55 无区分度 | ❌ 放弃 |

结论：**走本机 OCR 服务**（`POST /ocr` + `POST /scan_inventory`），纯前端只负责 UI。

## 三、已验证结论

### 3.1 资源与等级（整图空间定位）

| 截图 | 字段 | OCR 原文 | 结果 |
| :--- | :--- | :--- | :-: |
| 同步器 | 同步器等级 | `532〉`（右侧 `533` 是目标值，不取） | 532 ✅ |
| 同步器 | 信用点 | `持有 22762 K` | 22762K ✅ |
| 同步器 | 战斗数据辑 | `持有 240 M` | 240M ✅ |
| 同步器 | 芯尘 | `持有 6,738` | 6738 ✅ |
| 个人主页 | 同步器等级 | `I Lv532` | 532 ✅ |
| 个人主页 | 信用点 | `22762 K`（顶部资源栏） | 22762K ✅ |

**定位难点**：个人主页有 **9 个 `Lv` 干扰**（研究等级 240/158/161/137/157/170/159）。规则是「找『同步等级』标签 → 取同一水平带（Δy < 1.6×行高）且 x 更大的 `Lv\d+`」。

### 3.2 物品栏（彩带锚点 + 5×7 网格）

按参考项目 `recognize()` 的思路：**不做网格检测，用格子底部「彩色品质条」当锚点**。

```
HSV 饱和 → 横向形态学开运算 → 彩带 35 条
→ 网格 x0=153 / y0=415 / 步长 119 / 彩带 94×11 / 格子 94×94
→ 每格裁切放大 → OCR → 时长（N小时）+ 数量（x数字）
→ 格子主体红/蓝/黄像素占比 → 资源类型
```

| 项 | 结果 |
| :--- | :--- |
| 网格定位 | **35/35**（5×7 全中） |
| 时长标签 | **10/10**（`1/2/8/12小时`，置信度 1.00） |
| 数量 | **抽查 14 格全对**（`x3`/`x143`/`x2320`/`x5223`/`x10672` 等） |
| 资源类型 | 颜色占比法：红箱 748 红像素、蓝箱 1077 蓝像素，区分干净 |
| 耗时 | 35 格约 6.3 秒 |

### 3.3 图标素材评估

补充的 `_原生素材.png` 是干净箱子图标（240×240，无边框/标签/数量），但：

| 问题 | 说明 |
| :--- | :--- |
| 无法用于格子匹配 | 尺寸差（240→70）、格子边框遮挡、数量文字压住图标 |
| **图标不含时长信息** | 同资源不同时长只有 3 种图案：`1h=2h`（相似度 1.000）、`8h=12h`（1.000）、`24h` 独立 |
| 素材缺项 | `战斗数据辑` 缺 `_原生素材`；`芯尘` 缺 `_原始素材` |

→ 时长必须靠 OCR 读标签；图标暂不使用，留作未来区分「成长套组」等无颜色特征的箱子。

## 四、关键实现

1. **彩带锚点定位**：`bar` 宽即格子宽，格子 `rect = (bar.x, bar.y - 0.88*bar.w, bar.w, bar.w)`
2. **双通道读取**：像素风 UI 用 `INTER_NEAREST 4×` 最准（`2320` 从 `X22(0.71)` → `2320(1.00)`），但带标签的格子 `CUBIC 3×` 更全 → 两路互补，缺项才切下一路，覆盖率 28/35 → 33/35
3. **颜色判型**：只统计标签下方主体区的 HSV 饱和像素，避免蓝色标签本身干扰
4. **数量容错**：`xl→1`、`2X→2`、`bx→6`（字体把 1/0/2/6 认成 l/o/z/b），置信度打折
