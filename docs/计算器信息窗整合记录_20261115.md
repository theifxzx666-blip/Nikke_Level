## 1. A 套（主页 ⓘ 信息窗）原始规格 —— 恢复时的唯一依据

建立于 `df5cb16`（2026-10-16「界面优化批 1+2」），把常驻可见的 `p.hint` 原理说明收进标题旁 ⓘ。

| 项 | 规格 |
| :--- | :--- |
| 类名 | `.info-tip`（按钮，18×18 圆点 + 内联 SVG 圆圈 i） + `.info-panel`（面板） |
| 面板视觉 | 白底、`border-left: 4px solid var(--primary)`（**左侧绿边是标志**）、圆角 10、`box-shadow: 0 10px 30px rgba(0,0,0,.16)` |
| 面板宽度 | `min(380px, calc(100vw - 32px))` —— **固定宽度**，否则窄容器里会被压成竖条 |
| 定位 | `position:absolute; left:0; top:calc(100% + 6px)`，插在**按钮父节点内**（原地展开，不是 fixed 遮罩浮层） |
| 结构 | `.ip-title`（标题）+ `.ip-close`（✕，右上角）+ `.ip-body`（正文） |
| 交互 | 点开 / 再点收起 / 点面板外收起 / Esc 收起 / **全局同时只开一个** |
| 文案 | 集中在 `js/app.js` 的 `INFO_TEXTS`（11 条），HTML 只留空按钮 → 桌面/移动共用一份，文案不会漂移 |
| 动态文案 | 结果区四卡用 `data-tip-html` 覆盖静态文案（带当次计算的真实数字） |
| ⚠ 硬约束 | ⓘ 常落在 `<legend>` 内，移动端 `setupMobileForm()` 给 legend 绑了「点击折叠整段」→ **必须 `stopPropagation()`**，否则点图标会连整段一起折叠 |
| 挂载点（表单 5 处） | 当前基地等级 / 关卡进度 / 预计新主线推图收益 / 活动收益 / 其他 |
| 挂载点（结果区） | 4 张概览卡各 1 个 + 「达成目标方案」+ 「整合结论」 |

**11 条文案 key**：`tip-base` / `tip-stage` / `tip-stageclear` / `tip-event` / `tip-target` / `tip-card-1~4` / `tip-misc` / `tip-block3`

## 3. 本轮原型（v2 → v9）与原始设计的关系

原型走的是另一条路：**不碰 `index.html` / `app.js`，用运行时重排 + 单文件中内联**，所以能在线上退化版之上做出新形态，代价是**没法复用 A 套的组件代码**。

| 版本 | 信息窗相关 | 与 A 套的关系 |
| :--- | :--- | :--- |
| v2 | 设置抽屉贴右 | — |
| v3 | 设置改居中弹窗 | — |
| v4 | 基地收益小浮层（i + `.v4-pop`） | **形似 A 套但非同一实现**（无左侧绿边、无 ✕、无 11 条文案表） |
| v5 | 推图收益加口径 i | 同上 |
| v7 | 活动/推图明细搬进 700/600px 浮层 | 同上 |
| v8 | 入口统一成 16px 小 i；补 `.res-icon` 尺寸；结果页口径说明收进 i | 补齐了 A 套"入口是圆点"的视觉语言 |
| v9 | 推图奖励改表格常驻卡片；活动卡加收益摘要；活动行按国服排期预置 7 行并补活动名 | 明细不再藏，改为卡面直读 |

**结论**：原型现在的信息窗（`.v4-pop`）是独立实现，**不是 A 套**。若将来按 §4 恢复线上，两条路二选一：
- **A 路线（推荐）**：恢复 `bc4d8a8` 的 `INFO_TEXTS` + `.info-tip/.info-panel`，原型里的 `.v4-pop` 全部替换成 A 套组件 → 文案有唯一来源，桌面/移动一致
- **B 路线**：保留原型的 `.v4-pop`，把 11 条文案手工搬进来 → 少改代码，但两套并存、后续容易漂

## 6. 防复发

| # | 教训 | 措施 |
| :-: | :--- | :--- |
| 1 | 「路径重写」提交最容易夹带陈旧工作区 | 动路径的提交必须 `git diff --stat` 过一遍，净删行数异常即停 |
| 2 | 只按症状救文件会漏掉同批受损的其它文件 | 事故后按「同一次提交触碰的文件全集」恢复，不按症状挑 |
| 3 | `git log -S"关键词"` 是定位功能存亡的最快手段 | 遇到"以前做过现在没了"，先 `-S` 定生死 |
| 4 | Pages 有边缘缓存 | 每次恢复 bump `?v=`，并核对页面版本徽标 |
| 5 | 方案文档比代码更该跨设备 | 组件源码 + 11 条文案已落本文与附录，仓库丢了也能重建 |
