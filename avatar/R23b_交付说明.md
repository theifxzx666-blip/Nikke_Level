## 二、正确来源与打通链路

**权威来源 = 国服 `icons-char-si(sd)_assets_all_<hash>.bundle`（1 个包 = 全部 390 张小头像）**

| 环节 | 内容 |
|:--|:--|
| CDN | `https://down.nikke-cn.qq.com/prod/nk-patch/StandaloneWindows64/` |
| 包 | `pck/dp/bd06211/icons-char-si(sd)_assets_all_a1b865e6b97cd37bf4e328401ddb22b6.bundle` |
| 大小 | 9,457,380 B |
| 下载 | **必须 node `https.get`**（curl 遇 `(sd)` 括号返回 200+0B 假象） |
| 加密 | magic `4e4b4142` = **NKAB**（国服加密包） |
| 解密 | NAU：`[NAU,'d','-i',<目录>,'-o',<dec>]` —— `-i` **必须传目录** |
| 解密后 | magic `556e6974794653` = **UnityFS** |
| 导出 | AssetStudioCLI：`-t 0 -c 28,213 -s <解密后的文件>` |
| 产物 | **Sprite 390 个 + Texture2D 341 个** |

**采集口径**与既有方案 `拆包\04_临时车间\脚本\tmp_import_lib.py` 一致：
**原尺寸直接复制 + md5 校验**，不重采样、不补白、不跑 waifu2x。
