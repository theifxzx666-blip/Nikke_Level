## 〇、v2.9 更新点

1. **洗练模拟新增「定制模组消耗预估」**：洗练模拟面板末尾多出一张消耗卡，直接把「洗到更好要花多少」算给你看。
   - **每次洗练消耗**：按游戏规则 **重洗一次 = 锁定条数 + 1 颗**定制模组。
     不锁定 1 颗 / 锁 1 条 2 颗 / 锁 2 条 3 颗 / 锁 3 条 4 颗（锁 3 条再洗仍是 4 颗，且什么都不会变）。

## 二、当前装备（装备等级 + 词条）与洗练

**流程：选好角色 → ① 填「装备等级」+ 录入「当前装备词条」并保存 → ② 在洗练区设目标、看战力变化 → 满意则覆盖保存。**

1. **① 当前装备**（中栏上块）：每个部位卡头部先选 **`装备等级`**（强化 0 ~ 5，T9/T10 上限 5），
   下面 4 部位 × 3 条逐条选**词条类型 + 阶数**。点 **「保存当前装备」** 落盘；
   标题右侧标签实时显示 `未录入 / 未保存 / 已保存`。
   整套装备（**等级 + 词条**）**按角色分别保存** —— 换角色会自动切到那个角色自己的装备（没录过就是空白、等级默认满级 5）。
   改**装备等级**会立即重推面板三围与战力（每级 +10% 装备基础属性）。
   > **同一件装备不会出现重复词条**：本部位已被其它行选走的类型会自动**置灰**；把某行改掉后置灰立即释放。
2. **② 装备词条洗练**（中栏下块）：左列是①里已保存的**当前装备**（只读参照），右列选**洗练目标**；
   改动右侧即实时刷新右栏（战力变化 / 部位归因 / 逐条明细）。
   点 **「洗练目标 ← 当前装备」** 可把当前装备整份复制到目标再微调。
   这里**不做去重限制** —— 洗练时词条位置可能被打乱，重复类型是允许的。
3. 洗练结果满意时，点 **「确认洗练 → 覆盖当前装备」**：把目标固化为当前装备并保存（练度 + 整套装备词条一并落盘）。

### 洗练模拟（按部位）

右栏那块「洗练模拟」用来回答「**给这件装备洗词条，大概能洗成什么样、要花多少模组**」：

| 输入 | 说明 |
| :--- | :--- |
| 部位 | 头部 / 衣服 / 手部 / 鞋子（默认头部） |
| 参与重洗的词条位 | 列出该部位当前 3 条词条，**勾选 = 会被随机重洗**、**不勾 = 锁定保留现状**（至少要勾 1 条） |
| 洗练池 | 重洗时可能出现的词条类型（默认 9 类全开，可只留你想要的） |
| 阶数范围 | 每次重洗抽到的阶数区间（默认 1 ~ 15 均匀） |
| 模拟次数 | 蒙特卡洛抽样次数（默认 5000） |

输出：**当前整套战力** / **该部位现状**（内部战力 · 等效总阶 · 重洗几条）/ **洗后最低·最高** /
**洗后 P10·P50·P90** / **洗后平均** / **平均提升** / **提升分位** / **直方图** / **定制模组消耗预估**。

> 关键前提：模拟**只重洗你勾选的那几条**，其余词条（含另外三个部位）保持「① 当前装备」的现状不变，
> 所以「平均提升」就是「**只动这一件装备**能带来的期望收益」。
> 阶数在区间内**均匀抽取**、类型在池内**等概率抽取** —— 这是**模拟假设，不是游戏实测概率**，只用来比较相对高低。

### 定制模组消耗预估（v2.9）

模拟面板最下方一张卡，把「洗到更好大概要花多少模组」直接算出来：

| 字段 | 含义与算法 |
| :--- | :--- |
| **每次洗练消耗** | 游戏规则 **重洗一次 = 锁定条数 + 1 颗**。锁定条数 = 本部位**未勾选参与重洗**且有词条的行数。<br>不锁定 `1 颗` / 锁 1 条 `2 颗` / 锁 2 条 `3 颗` / 锁 3 条 `4 颗`（锁 3 条再洗 = 4 颗，且不会改变任何东西） |
| **单次「优于现状」概率** | 蒙特卡洛结果中**严格高于**当前整套战力的比例（只重洗勾选行，其余保持不动） |
| **期望洗练次数** | 几何分布 `1 / p` —— 「洗到第一次变好就停」的平均投入次数 |
| **洗出更好结果 · 期望消耗** | `每次消耗 ÷ p`，即需要备的模组量的期望值 |

> 池子里已经没有任何组合能超越现状时，末项显示「**该池已无法超越现状**」，而不是给一个误导性的 0。
> 换个说法：把「洗练池 / 阶数范围」缩小到只剩最优解，期望消耗会掉到最低——这就是**定向洗练**省模组的原因。

### 阶数与数值

所有涉及阶数的地方都是**下拉**，选项直接写成 `N阶·X.XX%`：
只认数值的玩家选阶数时一眼就能对上游戏里那行字。

```
攻击力    1阶·4.77%   ……   15阶·14.63%
暴击伤害   1阶·6.64%   ……   15阶·20.36%
优越代码伤害 1阶·9.54%   ……   15阶·29.16%
```

- 数值 = 静态表 `FunctionValue ÷ 100`（过载词条在游戏内**统一以百分比显示**）。
- 命中率 / 蓄力时间在表内是负数（内部方向），显示时取绝对值，与游戏一致。
- 切换类型时，该行阶数下拉会**按新类型重算整套数值**，并尽量保留原阶数。

## 三、公式与数据来源（全部实证）

```
战力 = round((攻击力×暴击系数×18 + (生命 + 防御力×100)×0.7) × num5 × 0.01)
num5 = 1.3 + 技能1×0.01 + 技能2×0.01 + 爆裂×0.02 + 物品内部战力×1e-4
暴击系数 = 1 + 暴击率×1e-4 × (暴击伤害×1e-4 − 1)      // 全角色 15% / 150% → 1.075

面板 = Group1 + Group2
Group1 = (等级基础 × 星级 + 循环室 + 好感度) × (1 + 核心×0.02)
Group2 = 装备 + 魔方 + 收藏品
```

| 项 | 来源 |
| :--- | :--- |
| 原始静态数据 | `E:\[3]Nikke\EpinelPS\cache\prdenv\149-…\StaticData.pack`（9,283 条全量表） |
| 战力公式 | 反编译 `NK_Common_System_Stat_StatUtility.CalcBattlePower` |

## 四、已知边界（明确标注，不猜）

1. **装备同厂加成**（`EquipCorporationStatBonus = 0.3`）：`WithCorpBonus()` 类文件不在反编译产物内，
   参考站口径为**不加成**（已用 13/13 打点证明）。客户端真实行为**待验证**，界面做成开关，默认关。
2. **过载词条的出现概率**：静态表不含概率。模拟器的**阶数分布（默认 1~15 均匀）与类型概率（池内等概率）都是假设**，
   不是游戏实测掉落/洗练概率，界面已标注；结果只用于比较相对高低。
3. **优越代码伤害口径**：本工具按客户端逐阶 `FunctionBattlepower` 精确计算（1 阶 +762）；参考站压成汇总口径（+761），差 ±1~5。
4. **静态数据版本**：当前用 **149 版**（152 版解密参数已变，未解）。新角色/新表可能缺失。
5. **SSR 专属收藏品上限只有 2 级**（0~2），与普通收藏品（0~15）不同，界面按各自上限处理。
