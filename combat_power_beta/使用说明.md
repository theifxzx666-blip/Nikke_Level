## 一、两种模式

### 练度模式（默认，推荐）

不再手抄面板三围。**填练度参数 → 自动推导出攻击/生命/防御 与附加效果战力**，公式与客户端逐位一致。

| 输入 | 作用域 | 说明 |
| :--- | :--- | :--- |
| 角色 | 角色级 | 从下拉选（168 人），自动带出职业/企业/武器/暴击 |
| **同步器等级** | **账号级** | 1 ~ 1400（被同步器挂载的角色，同步器等级 = 角色等级） |
| **通用研究** | **账号级** | 循环室·通用研究等级（原名「个人」） |
| **职业研究** | **账号级** | 循环室·职业研究等级，自动锚定当前角色职业（火力/防御/辅助型） |
| **企业研究** | **账号级** | 循环室·企业研究等级，自动锚定当前角色企业（极乐净土/米西利斯/泰特拉/朝圣者/反常） |
| 突破档 | 角色级 | 1~11，自动显示对应的 Grade/Core |
| 好感度 | 角色级 | 0 ~ 40（上限随突破档变化，表里有真实值） |
| 头/胸/臂/腿 强化 | 角色级 | 0 ~ 5（T10 装备视为常驻） |
| 魔方 + 等级 | 角色级 | 16 个魔方（遗迹突击魔方…），等级 0~15 |
| 收藏品 + 等级 | 角色级 | R / SR / SSR 专属（按角色武器或专属绑定自动挑），等级 0~15 |
| 装备同厂加成 ×1.3 | 角色级 | 默认**关**（参考站口径）；开/关可对比 |

> 账号级参数对**所有角色**生效，只需填一次；角色级参数随角色切换而变。
> 循环室「职业 / 企业研究」下方高亮小标签实时显示当前角色的锚定对象，避免填错那一档研究。

改任意一项即刻重推（「改动即推导」默认勾选）。

**同步器档位预览**：自动列出 4 档（当前 / 下一档 / +20 / +40）的面板与战力，用于判断「同步器升到下一档能涨多少」。

### 手填面板（专家模式）

保留原 v1 的用法：直接从游戏内抄 **攻击力 / 生命 / 防御力** 填进去。
适合核对、或练度参数拿不准时使用。

## 二、洗词条（核心功能）

1. 中间栏 **「洗前」** 设成当前配置。
2. 点工具栏 **「洗后 ← 洗前」** 复制一份。
3. 改「洗后」的词条 —— 右侧立刻显示战力变化、每部位归因、逐条明细。

| 功能 | 说明 |
| :--- | :--- |
| 双列洗前/洗后对比 | 4 部位 × 3 词条并排，实时 |
| 部位归因 | 头/衣/手/鞋 各自贡献了多少战力 |
| 单条词条试算 | 只换一条，单独看它值多少战力 |
| 九类词条战力单价表 | 9 类 × 15 阶 的战力增量表（每格上排战力 / 下排词条数值） |
| 洗练期望模拟 | 蒙特卡洛，给出 P10/P50/P90、均值、直方图 |
| 按游戏内战力标定 | 手填模式下用，反解「附加效果战力」 |
| 本地保存 / 导入导出 | localStorage + JSON |

### 阶数与数值

所有涉及阶数的地方都是**下拉**，选项直接写成 `N 阶 · X.XX%`：
只认数值的玩家选阶数时一眼就能对上游戏里那行字。

```
攻击力    1 阶 · 4.77%   ……   15 阶 · 14.63%
暴击伤害   1 阶 · 6.64%   ……   15 阶 · 20.36%
优越代码伤害 1 阶 · 9.54%   ……   15 阶 · 29.16%
```

- 数值 = 静态表 `FunctionValue ÷ 100`（过载词条在游戏内**统一以百分比显示**）。
- 命中率 / 蓄力时间在表内是负数（内部方向），显示时取绝对值，与游戏一致。
- 切换类型时，该行阶数下拉会**按新类型重算整套数值**，并尽量保留原阶数。

## 三、公式与数据来源（全部实证）

```
战力 = round((攻击力×暴击系数×18 + (生命 + 防御力×100)×0.7) × num5 × 0.01)
num5 = 1.3 + 技能1×0.01 + 技能2×0.01 + 爆裂×0.02 + 物品内部战力×1e-4
暴击系数 = 1 + 暴击率×1e-4 × (暴击伤害×1e-4 − 1)      // 全角色 15% / 150% → 1.075

面板 = Group1 + Group2
Group1 = (等级基础 × 星级 + 循环室 + 好感度) × (1 + 核心×0.02)
Group2 = 装备 + 魔方 + 收藏品
```

| 项 | 来源 |
| :--- | :--- |
| 原始静态数据 | `E:\[3]Nikke\EpinelPS\cache\prdenv\149-…\StaticData.pack`（9,283 条全量表） |
| 战力公式 | 反编译 `NK_Common_System_Stat_StatUtility.CalcBattlePower` |
| 面板分组 | 反编译 `NK_Common_System_Stat_CharacterStatHelper` |
| 换算常数 | `ConfigGameTable`（攻击 18 / 防御 100 / 生命 0.7 / 技能基础 1.3 / 装备每级 0.1 …） |
| 词条 9 类 × 15 阶 | `EquipmentOptionTable` → `StateEffectTable` → `FunctionTable.FunctionBattlepower` |
| 词条**显示数值** | 同上表的 `FunctionValue ÷ 100`（百分比）；口径经 nikke.gg / gamevika / gamewith / rappy-world 四源 T1·T15 逐位核对 |
| 循环室术语 / 企业名 | 系统文案库 `Locale_System.lss`（`RECYCLE_ROOM_RESEARCH_PERSONAL/CLASS/COMPANY`、`COMPANY_*`） |
| 技能/收藏品/魔方技能战力 | `SkillInfoTable` → `StateEffectTable` → `FunctionTable.FunctionBattlepower` |
| 角色中文名 / 魔方中文名 | 文本库 `文本库_zh-CN.xlsx`（`4_角色文本` / `8_道具名册`） |

## 四、已知边界（明确标注，不猜）

1. **装备同厂加成**（`EquipCorporationStatBonus = 0.3`）：`WithCorpBonus()` 类文件不在反编译产物内，
   参考站口径为**不加成**（已用 13/13 打点证明）。客户端真实行为**待验证**，界面做成开关，默认关。
2. **过载词条的出现概率**：静态表不含概率。模拟器的阶数分布是**假设**（默认 1~15 阶均匀），界面已标注。
3. **优越代码伤害口径**：本工具按客户端逐阶 `FunctionBattlepower` 精确计算（1 阶 +762）；参考站压成汇总口径（+761），差 ±1~5。
4. **静态数据版本**：当前用 **149 版**（152 版解密参数已变，未解）。新角色/新表可能缺失。
5. **SSR 专属收藏品上限只有 2 级**（0~2），与普通收藏品（0~15）不同，界面按各自上限处理。
